# 🎮 Hangman Game

A fun React-based Hangman game with theme toggling and responsive design.

## 📌 About

This project is based on the [Scrimba Hangman Capstone](https://scrimba.com/learn-react-c0e/~04n7) with additional features added by me, such as:

- Light/Dark theme toggle
- Custom styling and animations

### 🚀 Features

- Fully functional Hangman gameplay
- Responsive and mobile-friendly
- Clean UI with light/dark themes
- Custom error animations
